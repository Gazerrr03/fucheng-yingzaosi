# 生图资产管理

依据：`docs/生图任务书.md`、`docs/3D建模指南.md`。

## 目录

- `style/`：T0 风格候选；用户已选 01，副本为 `style_master.png`。
- `maps/`：T1–T4 城市底图及总览。缺控制图时生成的探索版本应放在 `maps/candidates/`，不得标记为结构验收通过。
- `clouds/`：T5 云雾透明素材。
- `ui/`：T6 纸面、基因图标、印章和地图标记。
- `concepts/`：T7 资产概念图，按资产 ID 分目录，保存 main / side 两视图。K11 桥、K12 树、K13 码头与船的变体分别记录；B02 按建模指南无需独立生成。
- `_management/prompts/`：实际发送给生图工具的完整提示词。
- `_management/manifest.json`：已生成文件的尺寸、SHA-256、状态和目视检查记录。
- `review.html`：全任务当前推荐版本预览，可按任务筛选、搜索 ID、切换透明图片底色、展开提示词与版本。
- `style-review.html`：T0 四候选存档审阅页。
- `_management/selected.json`：101 张当前推荐图片的映射；优先读取这个清单。
- `_management/QA.md`：已完成检查、实际尺寸与剩余核验项。
