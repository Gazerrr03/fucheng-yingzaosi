# 模型体检报告（32 个资产）

> 体检方式：`tools/blender/audit_models.py` 逐个导入 `assets/models/*.glb`，做几何检查，并渲染「全景 / 人眼高度正面 / 屋檐近景」三张图，图中放一个 1.7 米高的红色人形作尺度参照。
> 图片：`assets/model_refs/_audit/{ID}_{wide,eye,close}.png`；数据：`assets/model_refs/_audit/report.json`。
> 标准：用户要求精度达到「可以第一人称近看」，至少与《文明 6》的建筑相当。

## 1. 结论

- **体量、比例、尺度基本正确**：门洞、台阶、栏杆、垛口与 1.7 米人形对照合理，没有比例严重失真的模型。
- **有几处明确的缺陷**（第 2 节），无论是否升级精度都要先修。
- **精度与《文明 6》差距很大**：现在所有模型都是「方块 + 纯色」，只适合 3D 地块那样的远景俯视；人眼高度近看时缺少屋面、檐下、门窗、墙面的层次，也没有材质和投影（第 3 节）。

## 2. 缺陷清单（必须修）

| 资产 | 问题 | 原因 |
|---|---|---|
| K11a、K11b 石拱桥 | 拱洞没有挖空，拱形反而凸在桥面上方；桥身底部大片黑色闪烁；120 条非流形边、4～8 个退化面 | `arch_bridge()` 的轮廓多边形自相交，挤出后面片翻转 |
| K12a 柳 | 下垂的柳条是竖直尖刺，近看不像柳树 | 柳条用三棱锥表示，太粗且没有弯曲 |
| K07a、K07b、B01、B03、X07、K14、K12 系列 | 有共面重叠面（K07a 32 处、K07b 24 处、B03 20 处、X07 16 处、B01 12 处……），游戏里会闪烁 | 构件互相叠放时底面 / 顶面完全重合（院落铺地与房屋底面、院墙与房屋山墙等） |
| 所有带门窗的建筑 | 门窗是单面薄片，从侧面或背面看是透明的 | 门窗用一张贴在墙面外 3 cm 的面片表示 |
| B03 水轮 | 142 条非流形边 | 轮辋各段首尾相接处重叠 |

## 3. 与《文明 6》的差距

《文明 6》的建筑是手工建模加手绘贴图（每个资产一套 BaseColor、Normal 等多层贴图），远看轮廓清楚，近看有屋瓦、门窗、砖缝、小道具和投影。对照下来，我们缺的是：

| 部位 | 现状 | 需要达到 |
|---|---|---|
| 屋顶 | 四到八个平面；檐口一圈方条；正脊是方块 | 屋面有举折（逐段变陡的曲面）和檐角起翘；筒瓦一垄一垄看得出；檐口有瓦当和滴水；正脊有鸱吻，垂脊有垂兽和小走兽 |
| 檐下 | 一圈深色方条代表斗栱 | 每个柱头、开间都有斗栱（简化的栌斗、栱、昂）；额枋、雀替、檩椽头 |
| 门窗 | 黑色矩形窗，朱红矩形门 | 隔扇门和槛窗的格心棂条；门框、门槛、门簪；城门的门扇、门钉、包铁 |
| 柱与台基 | 圆柱、方柱础、平台基 | 鼓形柱础、阶条石、垂带踏跺、栏杆望柱头、散水 |
| 墙体 | 纯色 | 砖缝、勒脚、墙帽；城墙的马道、排水口、垛口射孔与望孔 |
| 材质 | 18 种纯色 | 带 UV 的贴图：砖、瓦、木纹、粉墙（含做旧与污渍）、石材；可选法线贴图 |
| 道具 | 无 | 灯笼、旗帜、石狮、水缸、匾额字样、柴堆、货摊等 |
| 光影 | 只有贴地的模糊椭圆阴影 | 方向光实时投影，近看才有体积感 |

## 4. 升级方案

精度提升不能靠逐个手改，要从构件库和渲染两头一起升级，然后批量重建：

**阶段 1：修缺陷（约半天）**
修 `arch_bridge()` 的轮廓、柳树、共面重叠，门窗改成有厚度的内凹门窗洞。重建受影响的模型。

**阶段 2：构件库 v2 + 一个样板（先定标准）**
- 屋顶：举折曲面、起翘、筒瓦垄（几何建模）、瓦当滴水、鸱吻 / 垂兽 / 走兽。
- 斗栱：参数化的简化斗栱组，按柱位排列。
- 门窗：隔扇门与槛窗的棂格、门框、门簪；城门门扇与门钉。
- 台基：鼓形柱础、垂带踏跺、望柱栏杆、散水。
- 城墙：马道、排水口、射孔。
- 先用新构件库只重做 **K04a 城门**，做成样板请你确认。面数预计从 1,944 增加到 3～6 万。

**阶段 3：材质与渲染**
- Blender 里给每类构件自动展 UV，用程序化材质（砖、瓦、木、粉墙、石，带做旧与污渍）烘焙成贴图，随 glb 导出。
- 游戏端：卡通着色加入贴图与环境光遮蔽；加方向光**阴影贴图**（实时投影）；按距离切换精模与简模（LOD），保证俯视地图和低端设备的帧率。

**阶段 4：批量重建**
样板通过后，用新构件库重建全部 32 个资产，并补道具。每个资产都按本报告的体检脚本重新出三视角对照图。

**代价**：模型总量会从现在的约 4.5 MB 增加到 30～60 MB（含贴图），首次进入地块需要更长加载时间，需要做按需加载。工作量是目前建模工作的数倍，建议样板通过后再全面铺开。

## 6. 阶段 3（2026-10-18）

**样板转正**
- `build_K04a.py` 现在产出 v2 精模 `K04a.glb`（42,506 面）。
- 旧的 v1 模型改名 `build_K04a_far.py` → `K04a_far.glb`（1,986 面），作为远景简模。

**远近模型切换（LOD）**
- 在 `data/models.json` 里给资产填 `far: "{简模 ID}"` 即可启用。
- 地块视图每帧按模型在屏幕上的宽度选择：小于 300 CSS 像素换简模，大于 340 换回精模；两个阈值之间不切换，避免来回闪。
- 精模与简模用同一套归一化规则摆放，切换时位置不跳。
- 实测：拉近时城门用精模，拉远时换成简模。
- 目前只有 K04a 有简模；其余资产升级到 v2 时，旧版自动成为各自的简模。

**贴图：程序化纹理（`src/view/surfaceShading.ts`）**

没有采用图片贴图。原因：程序生成的模型面数高，逐个展 UV、烘焙贴图会让每个模型多出 1～3 MB，近看还会糊。改为在着色器里按材质名、在模型自身坐标（米）上实时计算纹理：

| 材质 | 纹理 |
|---|---|
| 砖（brick*） | 一顺一丁错缝（单块约 0.46 × 0.13 米）、灰缝、逐块深浅、污渍、墙根潮气；地面为方砖 |
| 石（stone、marble） | 条石错缝、石面斑点、污渍 |
| 粉墙（plaster） | 水渍、竖向流痕、下部发暗 |
| 油饰木构（vermilion、teal、qing、wood） | 顺纹、旧漆深浅 |
| 瓦面、夯土、树皮 | 深浅变化；夯土另有分层 |

纹理太细（一个像素超过几厘米）时自动淡出，远处不闪。零下载，任何距离都清晰，所有现有模型同时受益。

**实时投影（`src/view/tileView.ts`）**
- 太阳方向的正交阴影贴图：4096²，覆盖整个地块。
- 4 次硬件比较采样，边缘柔和。
- 地块地面与所有模型都能接收和投射阴影；卡通着色中，阴影里的面压到最暗一档。
- 场景不变时不重画阴影贴图。
- 模型下面原来的模糊椭圆阴影改为只给立牌用。

**性能**（1440 × 900、2 倍像素密度）

| 浏览器 | 地块帧（平均） | 帧率 |
|---|---|---|
| Chrome（M4 / Metal） | 16.7 ms | 60 帧 |
| WebKit（headless） | 17.2 ms | 约 58 帧 |

- WebKit 每帧 CPU 不到 1 ms，属 GPU 填充瓶颈（2880 × 1800 画布 + 多重采样 + 移轴后处理）。分别关掉投影、纹理，帧时间都不变，说明瓶颈不在这两项新功能。
- 已把高像素密度屏上的多重采样从 4 倍降到 2 倍（平均帧时间 18.2 → 17.2 ms）。
- 画质自动降档（25 ms 以上降为 1 倍像素密度）照常生效。
- 真机 Safari 未测。

## 7. 阶段 4：全部资产升级到 v2（2026-10-18）

**做法**
- 每个资产的旧脚本改名为 `build_{ID}_far.py`，产出远景简模 `{ID}_far.glb`。
- 新的 `build_{ID}.py` 用构件库 v2 重建精模。
- `data/models.json` 里 32 个资产都填了 `far`，并各有一条 `{ID}_far`（`lodOf`）。登记用 `python3 tools/set_far.py ID ...`。
- 远景简模改为**按精模的包围盒归一化**（`tileView.placeModel` 的 `ref` 参数）。精模与简模外轮廓不完全一样（例如屋檐、船桨伸出），以前各自缩放到同一宽度，切换时会差 5～13%；现在两者同尺度、同轴心，切换不跳。

**构件库 v2 新增**（`tools/blender/kit2.py`）

| 构件 | 用途 |
|---|---|
| `roof_hip(kind=…)` | 歇山、庑殿、腰檐（只有下段坡与戗脊）共用一套曲面屋顶；走兽改为沿戗脊插值定位，不再悬空 |
| `roof_gable2` | 硬山（山墙封到屋面、墀头）/ 悬山（出际、博缝板）两坡顶，筒瓦垄、椽头、望兽 |
| `hall2` 扩展 | 多层楼阁（逐层收分，层间腰檐 + 平座木栏杆）、底层回廊（回廊柱上起下檐）、顶层重檐、庑殿 / 两坡屋顶；`dougong=False` 为无斗栱的小式建筑（厢房、民居、衙署次要建筑） |
| `railing` / `stone_balustrade` / `terrace` | 木栏杆；汉白玉栏杆（望柱、栏板、净瓶）；须弥座月台带踏跺 |
| `gate_platform2` 扩展 | 可不开门洞（墩台、角台）；顶边可选垛口或汉白玉栏杆 |
| `small_gate`、`barbican_square` | 瓮城门、箭楼、方形瓮城 |
| `house2`、`matou2`、`wall_openings` | 民居 v2：墙身留洞、实榻门（门簪、门枕石）、格窗、前廊、临街铺面（柜台、排门板）；马头墙 v2 |
| `enclosure2`、`wall_seg` | 院墙 / 隔墙：砖下碱、墙身、砖檐、两坡瓦帽 |
| `paifang2` | 牌坊（庑殿小顶）与棂星门（冲天柱、云冠） |
| `arch_bridge2` | 券石逐块错缝、吸水兽、分水尖、桥面条石、汉白玉栏杆随坡、抱鼓石 |
| `tree2`、`blob` | 递归分枝的树干 + 细分树冠团：阔叶、松、柳（成束三段垂条）、银杏 |
| `boat2` | 九剖面船壳、外板线、护舷、肋骨、舵与橹、竹篷骨架 |
