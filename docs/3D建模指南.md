# 3D 建模指南 v1（AI 生成）

> 具体的建模执行方案（参考板生图 → Blender 建模 → 验收）见 [建模任务书.md](建模任务书.md)。

## 1. 流程

```
资料 + 风貌参考 ──► 概念图（image 工具，见生图任务书 T7）
                    └─► 图生 3D 工具（Tripo / Hunyuan3D / Meshy 等）──► .glb
                                                          └─► assets/models/{ID}.glb ──► 检查与接入（第 3.1 节）
```

每个可交互格的 3D 视图**不是一个整体模型**，而是用「通用构件 + 少量专属主体」拼出来的：
- **通用构件**（城墙段、民居群、树、桥……）三城共用，按格子摆放。
- **专属主体**（昭明台、宾阳楼……）每个格子 0～1 个。
- **地面**直接用该格在底图上的那一块贴图，地形起伏和水面由程序生成。

这样 AI 生成的模型总数控制在 **30 个左右**，而不是每个格子各做一个。

## 2. 外观依据的优先级

1. **资料原文的明代描述**：例如昭明台「高三层，面南，翼以钟鼓」。
2. **资料里的古图**：明代府城图上画的城楼形式。
3. **现存或重建实物照片**：用来补细节，但要注意很多是后世重建的，比明代更华丽、更高大。规则是：**体量和层数按明代原文，细部（斗栱、脊饰、砖纹）参考照片**。
4. **同时期的通用形制**：明代地方城门、瓮城、衙署的一般做法。

## 3. 统一规格

| 项 | 要求 |
|---|---|
| 格式 | `.glb`（glTF 2.0 二进制），不用 Draco 或 meshopt 压缩，v1 的加载器先只支持未压缩格式 |
| 坐标 | Y 轴向上（glTF 标准）；尺寸和原点不限，游戏会自动归一化；**正面最好朝 +Z**（glTF 默认的前方，在游戏里就是朝南）。朝向不对也没关系，在 `data/models.json` 里填 `rotY` 修正即可 |
| 面数 | 通用构件 ≤ 30k 三角面，专属主体 ≤ 120k；检查脚本超过 12 万会提示，超过 60 万判为不可用 |
| 贴图 | 只用 baseColor 一张，内嵌在 glb 里，PNG 或 JPG；金属度、粗糙度、法线贴图都会被忽略，光照统一由程序做卡通三阶明暗 |
| 压缩 | **不要** Draco、meshopt、KTX2、WebP 贴图，图生 3D 工具导出时请选未压缩 |
| 材质 | 不要透明材质，水面由程序生成；没有贴图时会使用顶点色或材质底色 |
| 风格 | 风格化低多边形 + 手绘贴图；色板跟底图一致：赭石城砖、青灰瓦、朱红柱、墨绿树 |
| 命名 | 严格用资产 ID：`{ID}.glb`，例如 `X01.glb`、`K04a.glb` |

## 3.1 交付与接入流程

1. 把模型放进 `assets/models/`，文件名就是资产 ID，例如 `assets/models/X01.glb`。
2. 运行检查：`node tools/check_models.mjs`。它会列出每个模型的面数、贴图、网格包围盒，以及加载器不支持的扩展。
3. 导出到运行时目录：`python3 tools/export_assets.py --models-only`。导出时位置量化为 16 位、法线量化为 8 位（KHR_mesh_quantization，体积约减 43%），并把有远景简模的资产的精模包围盒写进 `data/models.json` 的 `bounds`。改过精模后必须重新导出，否则 `check_models.mjs` 会报 bounds 不符。
4. 刷新游戏，进入用到这个资产的地块。有模型的位置会自动换成模型，没有的继续显示概念图立牌。在浏览器控制台输入 `__tile.modelReport` 可以看到当前地块每个资产用的是模型还是立牌。
5. 如果大小或朝向不合适，改 `data/models.json` 里该 ID 的 `heroWidth`（作为地点主体时的宽度，米）、`width`（作为点缀时的宽度）、`rotY`（绕竖轴旋转的角度），保存后刷新即可。

游戏内的归一化规则：水平方向最长边缩放到显示宽度，底面落在格面上，水平居中，再按 `rotY` 旋转。点缀会再随机转 60° 的整数倍，避免整齐划一。

> 测试用模型可以用 `python3 tools/make_test_glb.py assets/models/X02.glb` 生成，它故意用了厘米单位、偏移原点和 90° 转向，用来验证归一化。测完记得删掉。

### 4.5 不需要 AI 生成、由程序生成的部分
- 地形起伏（山、丘陵）：用高度图 + 底图贴图。
- 水面（江、河、护城河）：用 shader。
- 六边形底座：浮空地块的侧面土层。
- 云雾：用 T5 的贴图做粒子或平面层。
