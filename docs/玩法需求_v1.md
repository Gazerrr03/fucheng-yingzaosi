# 三府古城 · 玩法需求 v1

> 定位：信息表达优先的轻量「可游玩地图」。纯 Web，自写 WebGL2 渲染，不用引擎。
> 配套文档：[内容清单_三城](内容清单_三城.md) · [生图任务书](生图任务书.md) · [3D建模指南](3D建模指南.md) · [技术选型_图形库](技术选型_图形库.md) · [资料问题报告](资料问题报告.md)

## 1. 已确认的决定

| 项 | 决定 |
|---|---|
| 目标 | 很轻的收集目标：点亮格子 → 点亮对应的卡；每城 7 项**基因**全部点亮即通关，另有数量不等的**拾遗**作为副目标 |
| 地图范围 | 城池 + 周边山水；格子尺度约 200 m，每城约 25～40 × 20～28 格；太远的山用地图边缘的「远景带」表示 |
| 进入 3D | 点击 → 云雾从四周合拢 → 加载 → 云雾散开 → 进入独立的 3D 地块视图 |
| 3D 模型 | AI 生成：先出概念图，再用图生 3D；采用「通用构件 + 专属主体」的组合方式 |
| 2D 美术 | 你用 image 工具出图；我提供任务书和每城的控制图 |
| 图形库 | WebGL2 原生 API；渲染后端可替换 |
| 时间基准 | 明代；清代及以后的内容只作为「后世」小注 |
| 内容来源 | 只用你给的资料和其中链接的 StoryMap |
| 资料矛盾 | 先用占位值，问题单独列在报告里 |

## 2. 流程与界面

```
[开场] 总览舆图（三城剪影）
   │ 选城（三城都开放，推荐顺序：襄阳 → 荆州 → 保定）
   ▼
[关卡地图] 2.5D 六边形地图
   ├─ 左上：城名 + 一句话简介
   ├─ 右侧：基因面板（7 枚印章，未点亮为灰）+ 拾遗进度
   ├─ 地图：拖拽平移，滚轮缩放（2～3 档），悬停时格子高亮并显示名称
   └─ 点击可交互格
         ▼  云雾合拢（约 0.6 s）→ 加载 → 云雾散开（约 0.8 s）
[3D 地块视图]
   ├─ 中央：浮空的六边形地块（中心格 + 一圈邻格），3D 模型
   ├─ 相机：自动缓慢环绕；可拖拽旋转、小范围缩放
   ├─ 浮窗：标题 / 年代 / 正文 / 史料原文摘录 / 「后世」小注 / 关联卡片
   ├─ 首次打开：浮窗读完（滚到底或停留 3 秒）→ 印章盖下的动画 → 点亮
   └─ 返回：云雾过渡回到地图，镜头停在刚才那一格
   ▼
[通关] 7 项基因全部点亮 → 城市印章盖章
[三城对比] 三城都通关后解锁
```

## 3. 地图层规格
- **网格**：尖顶六边形（同文明 6），每格约 200 m。网格线由 shader 绘制，平时很淡，悬停时加深。
- **格子数据**：`{ q, r, terrain, name?, kind: 'terrain' | 'ward' | 'site', siteId? }`。
- **地形分类**：水（江 / 河 / 濠 / 塘）、山、丘、林、田、城墙、城内坊市、关厢。
- **可交互格标记**：圆形徽记图标（城门 / 地标 / 坛庙 / 衙署 / 水 / 山），微微浮动；已点亮的显示勾或印章。
- **迷雾**：v1 不做，保留开关。

## 4. 3D 地块视图规格
- 地块 = 中心格 + 第一圈 6 个邻格，浮在空中；侧面露出土层；四周是云海。
- 地面贴图取自底图对应区域；山和丘用高度图做出起伏；水面用 shader。
- 场景用 JSON 装配：`{ siteId, pieces: [{ asset, pos, rotY, scale }] }`。
- 光照与后处理：平光加卡通明暗（二到三阶）、轻描边、移轴模糊、远处雾化。

## 5. 数据与存档
- 关卡数据：`data/{city}.json`，包含格子、地点、卡片文案、场景装配。
- 存档：localStorage 记录已点亮的卡片。
- 文案字段：`title, era, body, quote{text, source}, later?, cards[]`。
