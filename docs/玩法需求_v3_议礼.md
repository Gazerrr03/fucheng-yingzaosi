# 三府古城 · 玩法需求 v3：议礼与收敛

> 依据：`府城营建司-游戏策划书.docx`（v0.9，下称「策划书」）、`府城营建司-深化构想建议.docx`（下称「建议」），重点是建议 §1.4「议礼」与策划书 §4.6、§4.10 的地形豁免。
> 前序：`docs/玩法需求_v1.md`（探索：地图 + 地块 + 城池基因 + 拾遗）、`docs/玩法需求_v2.md`（营建：构件 + 方位风水评价 + 营建课 + 史书）。

## 0. 结论

**本轮做「议礼」的完整竖切**。两份文档都把它列为高价值项：
- 建议 §9 的「只做三件事」之一；
- 建议 §8 列为 P1，称「性价比最高的知识点玩法」；
- 策划书 §5.5 要求「每关一个原来如此」。

议礼恰好能把 demo 现有的两个模式接起来：
1. 玩家在**探索模式**里点亮地点、收集拾遗卡。这些卡就是「志书」，也就是议礼时可以拿出来的证据。
2. 玩家在**营建模式**里设坛、置署。方位违制时，礼部书吏会来诘问。
3. 玩家能拿出探索时解锁的方志，就能过关并得声望。

这样知识点从「结算页一行字」变成「先读到，后用上」。

**不在本轮做**（理由见第 2 节）：
- 千分制七维评分引擎；
- 工期、财力、夫役；
- 奏报勘核；
- 九年考课；
- 逾制路线；
- 形势判语；
- GPS、榜单、商业化。

## 1. 议礼：从文档到 demo

### 1.1 文档原意（建议 §1.4）

> 礼部书吏：府社稷坛当在城西北，今置于西门外，何也？
> A. 引方志为证——「城北濒汉，无地可设。」（需玩家已在志书中解锁该条方志）
> B. 依礼制改建于西北——但城北是水面，无法建造，此路不通
> C. 强辩——「地势使然，不必拘礼。」（扣分）
>
> 选 A 时弹出方志原文，玩家获得「通晓礼制」的声望加成。每关设计 1—2 个这样的「议礼」节点。

策划书 §4.6 还要求：「地形豁免」必须显式提示，并弹出方志原文。

### 1.2 现状与差距

| 文档要求 | demo 现状 | 差距 |
|---|---|---|
| 社稷坛礼制在西北，因地形可偏 | `fengshui.ts` 只认西北（NW +25），不认豁免；襄阳营建课目标写死「社稷坛设在城西北（得分 ≥ 80）」 | 与史实相反：照史实把坛放在西门少北，反而过不了关。**必须改** |
| 志书解锁方志 | 探索模式有拾遗卡和地点卡（`public/data/cards/*.json`），点亮后进度存本地（`src/game/progress.ts`）；`site:sheji` 卡只有一句概述 | 缺一张「社稷坛西移」的方志卡，营建模式也还没读取探索进度 |
| 书吏诘问，三个选项 | 无事件系统，营建模式只有放置预览和结算 | 新增议礼事件（数据 + 判定 + 对话框） |
| 声望「通晓礼制」 | 无声望 | 新增轻量声望：记名目，不做数值经济 |
| C 扣分 | 评分只有构件分和格局加分 | 结算加「修正项」一栏（策划书 §4.9 的形式） |
| 方志原文 + 出处 | 卡片有出处字段，`flag` 标记占位 | 议礼卡必须写明出处；没核实的照旧占位并记入报告 |

### 1.3 交互流程（襄阳社稷坛）

1. **触发**：在襄阳营建课里放下社稷坛，且同时满足：
   - 坛不在西北；
   - 城西北近郊的可建格不足（全是水）；
   - 坛在城外、离西门不远（就近替代）。

   如果坛放在了东南或城内这类明显违制的位置，就不触发议礼，照常扣分。
2. **书吏诘问**：一个模态卷轴，左上角一枚「礼部」印，书吏的问句用楷体，下面三个选项。
3. **选 A（引方志）**：
   - **未解锁时**：按钮灰显，并提示「此条方志载于探索模式·襄阳·社稷坛，点亮该地可得」，按钮可点、能跳转过去。
   - **已解锁时**：弹出方志原文卡，写明出处。坛的方位改判「地形豁免·有据」，不扣分，评语注明理由。获得声望「通晓礼制」。
4. **选 B（改建西北）**：地图高亮城西北近郊的格子（都是水面），书吏回一句「城北濒汉，无地可设」，然后回到选项。玩家亲眼看到「此路不通」本身就是知识点。
5. **选 C（强辩）**：
   - 坛照常按方位扣分；
   - 考成加一条修正项「强辩违礼 −N」；
   - 史书营建记里留一句贬语。
6. **记录**：议礼结果写进本次营建，结算页和史书都要看得到。选 A 的，营建记里写「议礼于部，引府志以对」之类。重修时不再重复触发；拆掉坛重放再触发。

  "options": [
    { "key": "A", "label": "引方志为证", "say": "城北濒汉，无地可设。", "requires": "lore:sheji_xiyi",

    { "key": "B", "label": "依礼制改建于西北", "effect": { "highlight": "NW-outside", "retry": true },

**与第 1 节原设计不同的地方**

1. **「西北无地」的判定排除了江滩。** 我们的襄阳底图在北城墙与汉江之间画了一两格宽的江滩。若把滩地算作陆地，西北就不算被阻断，书吏永远不会来问。现在规定：紧贴江河湖的格子汛期可没，不计入可建陆地（护城河边不算）。选 B 时书吏的答复也相应改为「西北城外非水即滩，汛期水至即没，无高燥之地可以设坛」，与地图上看到的一致。
2. **保定、荆州不用占位。** 两城的府城资料里已有依据（保定靴形为扩大射界，荆州不规则因依水），题目都是「城当方正，何以不方」，在考成前提出。
   - 这两条依据是现代概述，不是方志原文，所以选项 A 叫「引图籍为证」而非「引方志为证」，引文出处注明「现代概述，非方志原文」（资料问题报告第 21 条）。
   - 选 B 的答复（「改方则西面射界尽失」「截弯取直则城身入水」）是由资料推出的，也标了 flag 21。
3. **「城不方正」改用「沿用旧城址」判断。** 原想按城内面积与外接矩形之比判断方正，实测襄阳 0.60、荆州 0.93、保定 0.85：六边形格子太粗，荆州的依水随形、保定的西凸在格子上体现不出来。改为：城墙有六成以上沿用旧城址（荆州为锁定的旧城墙；保定为照底图旧城墙走向自筑）即触发。
4. **城形议礼暂时不影响得分，只给声望。** 现行评分（`fengshui.ts`）还没有平面形状一项，城形议礼选 A 只得声望（「通晓武备」「通晓地利」），选 C 照扣 5 分。等七维评分引擎加入 G2 平面形状后，A 再加上形状豁免。
5. **拆坛即作废。** 构件拆掉后，对应的议礼记录立即作废，重放要重新议，不再按格子保留。
