# 三城内容清单（关卡内容基准）

> **基准决定**
> - **时间**：以**明代**为准。三份 StoryMap 的标题都是「明代府城规划基因」，七项基因也是从 167 座明代府城统计出来的。清代及以后的事（荆州满城、清代城门改名、保定成为直隶省会等）只以「后世」小注的形式出现，不做成独立的格子。
> - **内容来源**：只用你给的资料，即 3 份府城资料、《襄阳府规划》、图片，以及资料里链接的 3 个 StoryMap（下文记作 SM）。网上搜到的内容**只作为 3D 外观参考**，不写进浮窗。
> - **有疑问的数据**：先照原文占位，标 ⚠️，详见 [资料问题报告.md](资料问题报告.md)。
> - **换算**：明营造尺约 0.32 m，1 丈 = 10 尺 ≈ 3.2 m，1 步 = 5 尺，1 里 = 360 步 ≈ 576 m。只用在 3D 比例和浮窗的「约合今」上，标注为约数。

## 0. 收集结构：「基因」+「拾遗」

一座城不只 7 项内容，所以分两层：

| 层 | 内容 | 作用 |
|---|---|---|
| **基因**（每城 7 项，三城相同） | 山水格局、平面形状、城墙周回、城门数量、坛庙位置、府署位置、城墙高厚 | **主目标**：7 项全部点亮即通关；三城都通关后解锁「三城对比」 |
| **拾遗**（每城数量不同） | 各城自己的地标、典故、沿革 | **副目标**：不影响通关，有收集进度，例如「襄阳拾遗 5/9」 |

点亮规则：每个可交互格关联 1～2 张卡（基因或拾遗）。打开这个格子的 3D 视图并看完浮窗，就点亮对应的卡。少数基因需要看完一组格子才点亮，例如「城门数量」要看完所有城门格。

格子类型：
- **地形格**（水、山、林、田、关厢）：只有悬停名称，不能打开。
- **坊市格**：悬停显示坊名，不能打开。
- **可交互格**：带图标、轻微发光，点击后进入 3D 视图。

## 1. 襄阳府（资料最全，建议作为第一关）

**地图范围**：北到汉江北岸（樊城只露南缘），南到岘山北麓，西含檀溪，东含汉江转弯处。约 6 × 5 km。
**底图几何来源**：现代测绘平面图（府城资料图 1.3，带尺寸）为主，明代府城图 1、2 用来确认门的位置和外城。

### 基因
| 基因 | 内容（原文要点） | 点亮方式 / 所在格 |
|---|---|---|
| 山水格局 | 依山傍水，三面环水一面临山。《读史方舆纪要》：「檀溪界其西，岘首亘其南，汉水如带萦乎东北，楚山若屏峙乎西南」 | 看完 **汉江、岘山、檀溪** 三个格中任意两个 |
| 平面形状 | 近方形；纵横主轴和城门都不在城墙正中，原因是明初在旧城基础上扩建 | **东北外城**格（拱辰门、震华门一带，即新城湾） |
| 城墙周回 | 12 里（SM：「周一十二里而赢」；《规划》：二千二百二十一丈七尺，合十二里一百三步），约合今 6.9 km | **城墙**格（西城墙段） |
| 城门数量 | 6 门：东**阳春**、南**文昌**、西**西成**、大北**拱辰**、小北**临汉**、东长**震华**，「俱有子城」（SM 引乾隆《湖广通志》） | **6 个城门格全部看完** |
| 坛庙位置 | 社稷坛居西北，风云雷雨坛居西南，郡厉居北 ⚠️ | **社稷坛**格（城外西北），另两坛作附属格 |
| 府署位置 | 城西南，临近襄王府 ⚠️ | **襄阳府署**格 |
| 城墙高厚 | 高二丈五尺，上阔一丈五尺，脚阔三丈，约合今高 8 m、顶宽 4.8 m、底宽 9.6 m | **临汉门**格（另带拾遗） |

### 拾遗
| 卡 | 来源要点 | 所在格 |
|---|---|---|
| 夫人城 | 西北隅的「城外城」，周长 70 余米，高 11 米，厚 18 米，夯土外砌城砖 | 城墙西北角 |
| 昭明台 | 南北主门轴线正中；「楼在郡治中央，高三层，面南，翼以钟鼓」；文选楼 → 山南东道楼 → 明代钟鼓楼 | 城中十字 |
| 仲宣楼 | 东南角楼，楚天四大名楼之一；现存为后世重建，高 17 m | 东南角 |
| 护城河 | 依托岘山、襄水的自流系统，经响水洞通汉江；宋代均宽 180 m 以上，最宽 250 m。SM：「东、西、南三濠……阔二十九丈，深二丈五尺」；「城北以汉江为濠」 | 西或南护城河 |
| 襄王府 · 绿影壁 | 平面图标注「襄王府」「绿影壁」；府署「临近襄王府」 | 城东南 |
| 府儒学 | 在府城东南，有大成殿、两庑、戟门、名宦祠、乡贤祠、棂星门、圣域坊、贤关坊 | 城东南（与襄王府错开） |
| 城门与瓮城沿革 | 宋乾道七年始建瓮城，土城改为砖城，直进直出的城门改为屯兵式瓮城门；明初邓愈重建 | 归入 **文昌门** 格 |
| 关厢与敌台 | 城门外有关厢，绵延约七里；嘉靖时在西郭、南郭、北郭设空心敌台 | 南关厢 |
| 汉江堤 | 堤距城墙二丈，用木桩、柴草、土石护岸，宽八尺，高五尺 | 北城外沿江 |
| 坊市 | 攀桂坊、冠英坊、思荣坊、攀龙坊、腾霄坊、科第坊、育贤坊、世科坊、魏清坊 | 坊市格悬停显示（位置为示意，不做拾遗） |
| 南门外两桥 | 延生桥（城南三里）、通济桥（城南半里，二孔，通南漳） | 城南地形格悬停 |

> 不放进地图的远处内容：隆中（诸葛武侯祠）、鹿门山、真武祠等，距城 5～15 km。可以做成地图边缘的「远方」箭头标签，v1 先不做。

## 2. 荆州府

**地图范围**：北面露出陵阜（八岭山、纪山方向，用远景带表示），南到长江北岸，东西把整个狭长城池包进来，再留些余量。约 8 × 5 km。
**底图几何来源**：「荆州府城古今位置对照图」（卫星图，带六门位置）为主，明代木刻城图用来确认内部建筑大致方位。

### 基因
| 基因 | 内容 | 点亮方式 / 所在格 |
|---|---|---|
| 山水格局 | 傍水，城绕水、水护城；「近州无高山，所有皆陵阜，故称江陵」；北有陵阜，南临长江天险，符合「山南水北」 | **长江**格 + **北郊陵阜**格 |
| 平面形状 | 不规则形，南北窄、东西长，夹在荆江与北面水系之间，「依水随形」⚠️ | **东城墙弯折处**格 |
| 城墙周回 | 18 里 381 步，约合今 11 km（今测周长 11.28 km，对得上） | **城墙**格 |
| 城门数量 | 6 门。明代名用 SM 引《明一统志》：东**镇流门**（楼宾阳）、东南**公安门**（旧名楚望）、南**南纪门**（楼曲江）、西门（旧名龙山，楼九阳）、小北**古漕门**（旧名维城）、大北**拱辰门**（旧名柳门）⚠️ | **6 个城门格全部看完**；浮窗加「后世」小注：清顺治三年改称寅宾、南纪、安澜、拱极、远安、公安 |
| 坛庙位置 | 同襄阳 ⚠️ | **社稷坛**格 |
| 府署位置 | 原在城西北，洪武年间迁到城东南 | **两个格**：府署旧址（西北）和府署（东南），两个都看完才点亮，表现「迁建」 |
| 城墙高厚 | 高二丈六尺，约合今 8.3 m；厚度不详 | **南纪门**格 |

### 拾遗
| 卡 | 来源要点 | 所在格 |
|---|---|---|
| 洪武砖铭 | 1364 年杨璟依旧基重建；砖上刻辰州、沅州提调、司吏、窑匠等人的姓名；湘鄂两省八府近五十县的砖经沅江水运而来 | 东城墙段 |

| 护城河 | 「阔一丈六尺，深一丈许，东通沙桥，西通秘师，北通龙陂诸水」；兼顾防洪、排涝、防御、运输 | 北护城河 |
| 公安门 · 水门 | 旧名楚望；SM 说城外掘池连通诸水（「唯一水门」出自网络资料，不写进浮窗） | 公安门格（与城门基因共用） |
| 历代城址 | 卫星图：战国楚纪南城、秦汉郢城、汉至唐初南郡城、明清荆州府城、清沙市 | **北郊**格（远景里标出纪南城、郢城方位） |

## 3. 保定府（文字资料最少，以府城图补空间信息）

**地图范围**：城池加周边水网（一亩泉引水、护城河、府河方向）。西部山地（朗山、松山、抱阳山、大茂山）距城数十公里，**只做成地图西缘的远景山带**，不画成真实距离。约 5 × 4.5 km。
**底图几何来源**：府城资料图 1.2（光绪《保定府城图》），街巷、坑塘、菜园都很清楚。时间上晚于明代，只借用它的空间格局 ⚠️。

### 基因
| 基因 | 内容 | 点亮方式 / 所在格 |
|---|---|---|
| 山水格局 | 依山傍水。山：西部丘陵和大茂山（古北岳），是防山西方向的第一道屏障；水：易水、徐河、石桥河、一亩泉、白沟河、瓦桥关，兼供漕运、农田，也是「水长城」防御体系；《畿辅通志》：「群山西峙，众水东潆」 | **西缘远山**格 + **一亩泉引水**格 |
| 平面形状 | 近方形，西城墙南段外凸约 500 m，形如朝西迈步的军靴（「靴城」），用来扩大射界对抗蒙古骑兵；代价是 3710 个堞口，城防成本激增 | **西南凸出部**格 |
| 城墙周回 | 12.92 里，约合今 7.4 km；元大将军张柔始筑 | **城墙**格 |
| 城门数量 | 4 门。资料没有给门名，先占位为「东门、南门、西门、北门」⚠️；府城图另标有「北水门」「西水门」 | **4 个城门格全部看完** |
| 坛庙位置 | 同上 ⚠️ | **社稷坛**格 |
| 府署位置 | 城正中 | **保定府署**格（府城图中心偏西有「府署」字样，需高清原图核对） |
| 城墙高厚 | 高 3.5 丈，上厚 1.5 丈，下厚 3.5 丈，约合今高 11.2 m、顶宽 4.8 m、底宽 11.2 m（三城中最高） | **南门**格 |

### 拾遗
| 卡 | 来源要点 | 所在格 |
|---|---|---|
| 张柔重建保州 | 1227 年重划市井，定民居，建衙署，筑寺庙，造园林，修土城，疏浚护城河 | 府署附近的坊市格 |
| 一亩泉引水与水力石磨 | 引一亩泉水入城，既能防御又改善水质；在城外利用水能建水力石磨 | 西北城外 |
| 「保卫大都，安定天下」 | 元 1275 年改称保定路；明洪武元年改为保定府；永乐元年为大宁都司驻地 | **北门**格（朝向京师） |
| 畿南首善 | 府城距京城 350 里，辖三州十七县 | 北门格的第二张卡 |
| 后世 · 直隶省会 | 清康熙年间定为直隶省会，直隶总督署驻此 | 只作为府署格的「后世」小注 |

> 保定的拾遗明显偏少。如果你同意补充，可以加入古莲花池、大慈阁、钟楼等（府城图上有「莲池书院」字样），但这些内容需要你提供资料或允许我引用外部资料。**这一点需要你决定**。
