# 府城营造司 · 玩法需求 v4：进入流程与天下舆图

> 依据：2026-10-18 验收意见。
> 前序：`玩法需求_v1.md`（探索）、`v2`（营建）、`v3_议礼.md`（议礼）。

## 0. Goal

**让玩家从「主界面 → 选模式 → 选城/选址 → 营建」一路顺下来，并把自定义模式做到文明六的基线。**

验收意见原话的要点：

1. 舆图上 3 座城，经典模式列了 4 座城，对不上，也重复了。整理后：**舆图上 4 座城，这 4 座城就是经典模式的选关**。
2. 进游戏先看到**主界面**，选「经典模式」才出现舆图；舆图上 4 座城**按顺序解锁**。
3. 「自定义模式」才是现在真正的玩法：一张**宏大的真实中国地图**，参考文明六「真实地球」那样用六边形拟合真实比例。
4. 交互太繁琐，要学文明六。
5. 能搭出来的模型质量很低，看上去黑黢黢一片。

文明六基线在本项目里具体指：

- 一张真实比例的六边形大地图，地形一眼能认出来（山、丘、平原、江河、湖、海、高原）；
- 先在大地图上**择址建城**，选址时有提示告诉你这里好不好；
- 进城后**选中一种建筑，全图直接标出每格能得几分**（文明六的区域加成提示）；
- 镜头顺手：拖拽平移、滚轮缩放、键盘平移、迷你地图；
- 建筑模型清楚、有颜色，不是一团剪影。

## 2. 本轮不做

- 回合、钱粮、人口增长等经营系统（文明六的经济层）。先把地图、选址、营建的手感做到位，再决定要不要加。
- 真实 DEM 高程。本地没有地理数据，T06 的矢量按经纬度手工整理，精度为示意级（约 0.2°）。脚本的输入格式与 Natural Earth 兼容，以后拿到数据可以直接替换。
