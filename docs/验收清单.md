## 1. 建议的验收路线（约 20 分钟）

**从干净进度开始**：在浏览器控制台运行 `localStorage.clear()` 后刷新。

### A. 探索与 3D 模型
1. 总览页 → 点「襄阳」。底图上有六边形网格，悬停高亮，地点有立牌或图标。
2. 点「昭明台」进入地块：云雾过渡后看到 3D 模型和浮窗。
3. 在地块里拉近、拉远、旋转。
   - **看**：拉近时城楼的斗栱、瓦垄、门钉清楚；拉远后换成简模，切换时不跳；地面和模型有投影。
4. 再看两三处：临汉门（X02 两层城楼带回廊）、府儒学（X06 院落）、护城河（K11b 石拱桥）。
5. 回到地图，确认基因进度和拾遗计数增加。

### B. 议礼（本轮重点）
1. 总览页 → 「经典模式 · 营建课」第二课 · 襄阳。
2. 打开「坛庙」页签，把**社稷坛**放到城**西门外**（罗盘「兑」位附近的城外陆地）。
   - **应当**：右下弹出礼部书吏的诘问。A 是虚框，提示「此条方志载于探索 · 襄阳 · 社稷坛」。
3. 选 **B**：地图移到城西北，近郊一片描朱框；书吏答「非水即滩……此路不通」；B 被划去。
4. 点「暂且搁置」。右侧出现「议礼」栏，带「再议」按钮。
5. 点 A 旁的「去探索模式查阅」，进入襄阳探索，点开「社稷坛」地块，浮窗里应有拾遗「社稷坛西移」，附《古今图书集成》所引《府志》原文。
6. 回到襄阳营建课（布局还在），点「再议」→ 选 **A**。
   - **应当**：弹出方志原文和出处；按钮写「存案 · 得「通晓礼制」」。
   - 右侧目标「社稷坛合制」打勾；悬停坛上，评语为「地形豁免 · 有据」。
7. 换一种结果试：用「拆除」拆掉坛、在原处重放，书吏会再问一次；这次选 **C**，总评扣 5 分，「议礼」栏记「考成修正 −5」。
8. 回总览页，左栏「声望」下出现「通晓礼制」。
9. **荆州课**：一进去，右侧「议礼」栏就写「考成之前，部臣将有一问」。点「再议」，题目是「城郭曲折不方，何也？」。A 需先在探索模式点亮「东城墙弯折处」。
10. **保定课**：照底图旧城墙走向把城墙筑完，才会出现同类诘问；筑成方城则不问。

### C. 营建课过关与史书
1. 任选一课把「本课目标」做完 → 「过关」。
2. **看**：过关弹窗里有议礼结果和修正项；史书卷轴的营建记里有议礼的那一句（选 A、选 C 措辞不同）。

## 2. 已知问题与限制

| # | 问题 | 说明 |
|---|---|---|
| 1 | 城形议礼不影响得分 | 现行评分没有平面形状一项，选 A 只得声望；选 C 照扣 5 分。等七维评分引擎 |
| 2 | 襄阳社稷坛「以城北濒汉故也」未核实 | 策划书所引这句没能在网上找到原文，已不再引用；改由玩家陈说并注明推断（资料问题报告第 18 条） |
| 3 | 保定、荆州议礼依据为现代概述 | 来自府城资料，不是方志原文，选项因此叫「引图籍为证」（第 21 条） |
| 4 | 资料数值冲突未处理 | 保定周回（策划书约 6 里 vs 资料 12.92 里）、襄阳底阔等，本轮只记录不改（第 19、20 条） |
| 5 | 真机未测 | iPhone / iPad Safari 与低端设备没有测过；headless WebKit 地块帧约 18 ms |
| 6 | 底图超分未做 | 需要你同意下载 Real-ESRGAN，或提供放大后的底图 |
| 7 | 没有版本管理 | 项目文件夹不是 git 仓库，本轮改动都直接在工作目录里，无法回退到某个版本 |

## 3. 验收时请特别留意
- 议礼的文案语气（书吏的问与答、营建记的句子）是否合意。
- 选 B 时地图自动移到西北，会不会让人迷失方向。
- 近景精模的精度，对照之前说的「可以第一人称近看、至少相当于《文明 6》」。
