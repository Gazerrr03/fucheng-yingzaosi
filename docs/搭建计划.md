## 2. 两个关键技术决定

### 2.1 斜俯视底图怎么叠六边形网格：用单应性矩阵（homography）把画面「摊平」到地面

- 在每张底图上标 4 个以上的地面参考点，比如城墙四角，对应到地面坐标（米）。由此算出一个 3×3 的单应性矩阵 H。
- **渲染时**：地面是一个世界坐标平面，fragment shader 用 H 把世界坐标映射回原图的 UV 来取色。相机固定为和原图一致的倾角，只能平移和缩放，这样看到的就是原画本身，没有变形。
- **网格和拾取**：都在世界坐标里计算，所以六边形是规则的；在画面里会自然呈现近大远小的透视，效果和文明 6 一样。
- **进入 3D 地块**：同样用 H 从原图裁出这一格的地面贴图，再从地图视角连续推近，衔接很顺。
- 好处：**不用重新生成底图**，现有成果全部保留。

### 2.2 控制图改为「反向标定」

底图已经画好了，就不再先做控制图再重绘，而是反过来：在现有底图上标出每一格「是什么」。为此做一个**开发用的标定工具**（一个内部网页）：
1. 载入底图，点击设置参考点，得到 H。
2. 调整网格的原点、格子尺寸和旋转。
3. 用笔刷给格子刷类型：水、山、林、田、城墙、坊市、关厢。
4. 放置地点（siteId），关联 `内容清单` 里的卡片。
5. 导出 `data/{city}.json`。

如果标定时发现画面和资料对不上（比如城门数量不够），有两种处理：
- **v1**：允许地点格放在「画面上大致合理的位置」，地图图标会指示它。
- **之后**：对那一小块做局部重绘。

## 3. 工程结构

```
demo/
  docs/                    文档
  assets/raw/              生图原件（不改动）
  tools/
    export-assets.mjs      读 selected.json → 缩放/转 webp → public/assets/
    calibrate/             标定工具（开发用网页）
  public/assets/           运行时资源（脚本生成）
  data/                    xiangyang.json / jingzhou.json / baoding.json / cards.json
  src/
    main.ts
    game/                  状态机（总览 → 地图 → 地块 → 返回）、收集进度、存档
    scene/                 hex.ts（坐标/拾取）、camera.ts、homography.ts、tileScene.ts
    render/                api.ts + webgl2/（context、shader、texture、mesh、post）
    ui/                    HUD、浮窗、印章动画、云雾过渡（DOM + CSS）
  index.html
  vite.config.ts           只做开发服务器和打包，不进运行时
```

## 4. 分阶段计划

| 阶段 | 内容 | 产出 / 验收 | 依赖 |
|---|---|---|---|
| **P0 骨架** | Vite + TS 工程；资产导出脚本；WebGL2 上下文和渲染循环 | 能打开一个空场景，资源导出到 `public/assets` | 无 |
| **P1 地图视图** | 地面平面 + 单应性取色；固定倾角相机（平移、缩放、边界）；六边形网格 shader；悬停高亮和拾取；地点徽记（精灵）；右侧基因面板 | 襄阳底图上能流畅拖动、缩放，悬停时格子高亮并显示名称 | P0 |
| **P2 标定工具 + 襄阳数据** | 标定工具；襄阳的 H、地形、地点、卡片文案（来自内容清单） | `data/xiangyang.json` 完成 | P1 |
| **P3 关卡闭环** | 点击地点 → 云雾合拢 → 3D 地块（**先用占位**：六边形浮空地块 + 地面贴图 + 概念图做成立牌）→ 浮窗 → 印章点亮 → 云雾返回；localStorage 存档；7 项基因点亮后通关盖章 | **襄阳从头到尾能玩通** | P2 |
| **P4 3D 接入** | glb 加载器 + 归一化（缩放、落地、朝向）；卡通明暗 + 描边 + 移轴；场景装配 JSON；先做襄阳要用的约 20 个资产 | 襄阳的地块视图换成真 3D | P3 + 图生 3D 结果 |
| **P5 扩展** | 荆州、保定的标定和数据；总览选关；三城对比页 | 三城全部可玩 | P4 |
| **P6 打磨** | 底图超分、局部重绘、音效（可选）、性能和兼容性检查 | 可以对外演示 | — |

**P3 结束时就有一个能完整体验的襄阳版本**，3D 用概念图立牌顶替。这样 3D 资产的生产不会卡住整体进度。
