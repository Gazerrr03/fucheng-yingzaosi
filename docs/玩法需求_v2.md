# 三府古城 · 玩法需求 v2：营建、风水、史书

> 在 v1「寻访点亮」的基础上，加入「营建」玩法：经典模式每关教一种府城规划思路，自定义模式在真实地图上自由筑城。每次营建都会写进一卷类似地方志的「史书」。
> 上一版：[玩法需求_v1](玩法需求_v1.md)

## 0. 需求原文拆解

| 原话 | 拆成的要点 |
|---|---|
| 自定义摆放模式，取现实中的真实地图（参考《文明 6》真实地图） | 新增一个模式；地图来自真实地理；玩家自己摆建筑拼出古城 |
| 只保留现在的绕城高速以内作为可建造的土地 | 可建范围 = 绕城高速围合的多边形；范围外只显示，不能建 |
| 地形用现状地形或建国初期的地形，倾向更早的 | 地形数据优先取建国初期（约 1950 年代）的地形图，还原被城市化抹掉的山丘、河汊、湖塘 |
| 参考《东方：平野孤鸿》的方位风水评价 | 建筑摆放后按方位、地形、相互关系打分，并给出传统文化讲解 |
| 府衙、坛庙、生活区、商业区等位置要更有可玩性和科普性 | 每类建筑都有方位偏好和地形偏好，评价文字讲出处（如明代坛壝制度、《考工记》） |
| 经典模式每关有一个主要的规划思路教学 | 每关一个主题 + 3～5 个目标；关卡按难度递进 |
| 襄阳：三面环水的防御性府城；保定：平原上的堡垒；武昌：含山的府城 | 三个主题直接采用；荆州补一个「城绕水、水护城」；武昌是新关卡 |
| 打完经典关卡后，自定义模式更容易上手 | 经典关卡用的是和自定义模式同一套构件、同一套评价规则 |
| 「史书撰写」：玩家昵称，关卡完成或自定义修改后生成类似史书的记载 | 名号设置；中文纪年（公元 + 农历 + 干支）；古文风格的「营建记」；可以翻阅历次记载 |
| 有利于反复修改重建和玩家之间分享，形成社区文化 | 每次修改留一卷；城池可以导出分享码，别人导入后续修；记载可以导出成图片 |
| 风格参考给出的截图 | 暖色夕照、低多边形、拟人猫官吏；营建视图的配色向这个方向靠 |

## 2. 两个模式的关系

```
总览
 ├─ 经典模式（按教学顺序）
 │    每座府城：寻访（v1，点亮七项基因）+ 营建课（v2，一个规划主题）
 │    保定 → 襄阳 → 荆州 → 武昌
 └─ 自定义模式
      选真实地图 → 自由营建 → 风水评价 → 修成一卷「营建记」→ 分享码
```

- 两个模式用**同一套构件、同一套评价规则**。经典课教会的东西，在自定义模式里直接用得上。
- 营建课不需要先完成寻访，但总览里会建议先寻访再营建。

## 3. 方位风水评价规则

方位以「城心」为原点分八方（北为坎、东北为艮、东为震、东南为巽、南为离、西南为坤、西为兑、西北为乾）。城心 = 城墙围合区域的中心；没有城墙时取所有建筑的中心。

| 构件 | 方位偏好 | 地形 / 关系偏好 | 依据（讲解里会说） |
|---|---|---|---|
| 府署 / 县署 | 城中或偏北，坐北朝南 | 在城内；地势不低于周边 | 明代府城多数府署居中或偏北（规划基因「府署位置」） |
| 学宫（文庙） | 东南（巽位） | 在城内；近水更佳（泮池） | 东南为文昌位，地方志「学宫多在治东南」 |
| 城隍庙 | 不限，宜近府署 | 在城内 | 城隍为一城之神，与官署相表里 |
| 社稷坛 | 西北 | 在城外近郊 | 洪武制：社稷坛在府治西北 |
| 山川坛（风云雷雨山川坛） | 南 | 在城外近郊 | 洪武制：山川坛在城南 |
| 厉坛 | 北 | 在城外 | 洪武制：厉坛在城北 |
| 钟鼓楼 | 城中 | 在城内、近府署 | 晨钟暮鼓，报时于全城 |
| 市肆 | 近城门、近码头 | 在城内或关厢 | 《考工记》「面朝后市」；明清府城市集多依城门与水路 |
| 民居坊 | 不限 | 不在水里、不在陡山；成片更佳 | 坊巷连片，避水患 |
| 城墙 | — | 围合成闭环；沿山脊、沿水岸更省力 | 规划基因「城池平面形状」「城墙周回」 |
| 城门 | 四正方向各一 | 必须在城墙线上 | 规划基因「城门数量」 |
| 瓮城 / 敌台 | — | 贴着城门 / 城墙；无险可守的一面更需要 | 襄阳夫人城、保定四门瓮城 |
| 角楼 | 城墙转角 | 在城墙上 | — |
| 码头 / 水门 | — | 贴着江河 | 荆州、襄阳依水运 |
| 护城河 | — | 贴着城墙外侧 | — |
| 书院 / 魁星楼 | 东南 | 近学宫；魁星楼宜高处 | 文风所系 |

整体格局另有加分：**背山面水**（城北或西北有山、城南或东南有水）、**城墙闭合**、**四门俱全**、**护城河环绕**。

评分：每座建筑 0～100 分；全城取平均再加整体格局分，换成五个等第——上上、上中、中上、中、下。

## 4. 经典关卡教学

| 序 | 府城 | 主题 | 学到什么 | 目标示例 |
|---|---|---|---|---|
| 一 | 保定 | 平原上的堡垒 | 无险可守时，城防全靠人工：闭合城墙、四门瓮城、四角角楼、外绕护城河；府署居中 | 城墙闭合 · 四门皆有瓮城 · 四角角楼 · 府署居城中 |
| 二 | 襄阳 | 三面环水的防御性府城 | 借水为险：北临汉江、东西有濠，唯一的陆路面（西南、南）要重点设防；坛壝按方位出城 | 陆路一面设敌台或瓮城 · 汉江边设码头 · 社稷坛在西北 · 山川坛在南 |
| 三 | 荆州 | 城绕水、水护城 | 水系组织：护城河连江、水门进城、码头与市肆相依 | 护城河环城 · 设水门 · 市肆邻码头 · 学宫在东南 |
| 四 | 武昌 | 含山的府城 | 山在城中：城墙跨山、府署依山之阳（南麓）、高处设楼望江 | 城墙把蛇山围进城 · 府署在山南 · 楼阁在山头临江 · 市肆在平地 |

- 保定、襄阳、荆州沿用 v1 已标定的地形格；武昌是新关卡，地形为示意级（见 T08）。
- 每课开场有一段讲解（主题 + 史实），过关后生成该城的「营建记」。

## 5. 史书（营建记）

- **名号**：玩家填昵称和官职（知府、同知、通判、知县……），第一次营建时询问，之后可以改。
- **纪年**：「公元二〇二六年 · 岁次丙午 · 九月十七日」。农历和干支用浏览器自带的农历日历换算，不需要额外数据。
- **正文**：仿宋明「重修记」和地方志的写法，四段：
  1. 起：纪年 + 名号 + 「莅任/重修某府城」；
  2. 地：山川形势（由地形算出：「北枕汉水，南依岘山」）；
  3. 工：营建了什么（城墙周回几何、门几座、坛庙方位）；
  4. 评：风水等第 + 一句评语；末尾署名「某某谨记」。
- **卷宗**：每次过关、每次自定义保存都写一卷，按时间倒序翻阅。
- **分享**：城池分享码（地图编号 + 构件列表，压缩成一串文字），别人导入后可以在你的城上续修，新的记载会写「续修」；记载可以导出 PNG。
- **社区**：v2 只做到可复制的分享码和图片；真正的线上社区（广场、点赞、续修链）需要后端，列为以后的事。

## 6. 美术方向（参考截图）

- 暖色斜阳：主光偏金黄（约 #f2c37a），阴影偏蓝灰（约 #5a6070）；
- 低多边形、木构为主：木栏、深灰瓦顶、白墙；
- 拟人猫官吏、小吏、百姓，作为后续「人物」层（v2 不做）；
- 营建视图配色向这个方向靠：地面暖沙色、山体赭绿、屋顶深灰、水面青蓝。

## 7. 真实地图数据

| 项 | 做法 |
|---|---|
| 可建范围 | OSM 中绕城高速的路线，闭合成多边形（GeoJSON） |
| 地形 | 首选 1950～60 年代 1:5 万地形图（等高线数字化）；没有时用 SRTM 30 m DEM，并人工把已填的湖塘、已削的山丘补回去 |
| 水系 | 同期地形图上的江河、湖塘、溪沟；没有时用 OSM 水系，人工补回已消失的河汊 |
| 格子尺度 | 自定义地图每格 300 m（重庆绕城高速以内约 2～3 万格；缩小时地形预渲染成位图） |
| 工具 | `tools/build_real_map.py`：输入 DEM（ESRI ASCII 栅格）、范围和水系 GeoJSON，输出 `public/data/plan/{city}.json` |

本轮先附**重庆示例图（示意级）**：长江、嘉陵江在朝天门交汇，渝中半岛、中梁山、铜锣山、南山的大势按印象画出，没有用真实数据。拿到真实 DEM 和地形图以后用 T12 的工具重新生成。
